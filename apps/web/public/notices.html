Third-party software

Each build includes third-party license texts and notices and a versioned license inventory for bundled JavaScript, generated CSS, copied components, and PDF preview decoders. These files are generated from the build and installed packages, not a manually maintained list of direct dependencies.

Packages removed from the final JavaScript by tree shaking are not distributed and are excluded from this inventory. No web fonts are shipped; the interface uses your system fonts.

PDF.js preview decoders are distributed locally with their upstream license texts: PDF.js, JBIG2/CCITT, PDF.js JBIG2 integration, OpenJPEG, and PDF.js OpenJPEG integration.
